# AQJ-autonomous-quick-jack
CAD and physics-simulation model of an Autonomous Quick Jack (AQJ) — a self-positioning device that lifts a vehicle for tire changes with minimal human input. Includes SolidWorks parts/assemblies, a MATLAB Simscape Multibody model with contact forces, SolidWorks Simulation load cases, and project documentation. UniNa DMISI course project.
